# MNIST 图像分割 — 从零实现 LeNet-5 魔改版

⚡ 不用 PyTorch，不用 TensorFlow，纯 NumPy 实现图像分割

## 📖 项目简介

本项目从零实现了一个**图像分割模型**，基于 LeNet-5 魔改，在 MNIST 数据集上进行**前景（数字）分割**。模型将输入图像中的每个像素分类为“数字”或“背景”，输出与输入同分辨率的二值掩码。

- ✅ 纯 NumPy 实现，无任何深度学习框架依赖
- ✅ 完整的**前向传播 + 反向传播**（手写梯度）
- ✅ 对称的 **U-Net 风格**架构 + 跳跃连接
- ✅ 支持 **断点续训**，随时保存和加载模型
- ✅ 支持 **Dice Loss** 和**加权交叉熵**切换

---

## 🎯 项目背景

### 从分类到分割

| 任务 | 输入 | 输出 | 目标 |
|------|------|------|------|
| **分类 (LeNet-5)** | 32×32 图片 | 1 个数字 (0~9) | 识别是什么数字 |
| **分割 (本项目)** | 32×32 图片 | 32×32 掩码 (0/1) | 识别每个像素是否属于数字 |

分割的难点在于需要**像素级的空间精度**，而不仅仅是全局类别判断。

- **为什么不用框架？** 理解深度学习“学习”的本质——梯度就是矩阵乘法；掌握反向传播的每一个细节；拥有完全透明的代码，调试有底气。

## 🧠 模型架构

### 编码器 (Encoder) — LeNet-5 风格

| 层 | 操作 | 输入 → 输出 | 通道变化 |
|----|------|-------------|----------|
| Input | - | 32×32 | 1 |
| Conv1 | 5×5, pad=0, stride=1 | 32×32 → 28×28 | 1 → 6 |
| ReLU1 | - | 28×28 | 6 |
| Pool1 | 2×2, stride=2 | 28×28 → 14×14 | 6 |
| Conv2 | 5×5, pad=0, stride=1 | 14×14 → 10×10 | 6 → 16 |
| ReLU2 | - | 10×10 | 16 |
| Pool2 | 2×2, stride=2 | 10×10 → 5×5 | 16 |
| **Conv3 (瓶颈)** | 1×1, pad=0 | 5×5 → 5×5 | **16 → 16** |

**关键设计** 瓶颈保留 5×5 空间信息，而不是压缩到 1×1。

### 解码器 (Decoder) — 与编码器对称 + 跳跃连接

| 层 | 操作 | 输入 → 输出 | 跳跃连接 |
|----|------|-------------|----------|
| Upsample1 | bilinear, scale=2 | 5×5 → 10×10 | - |
| Concat1 | concat | 16 + 16 → 32 | ← Conv2 (16×10×10) |
| Conv4 | 3×3, pad=1 | 32 → 6 | - |
| ReLU4 | - | 10×10 | - |
| Upsample2 | bilinear, scale=1.4 | 10×10 → 14×14 | - |
| Concat2 | concat | 6 + 6 → 12 | ← Pool1 (6×14×14) |
| Conv5 | 3×3, pad=1 | 12 → 6 | - |
| ReLU5 | - | 14×14 | - |
| Upsample3 | bilinear, scale=2 | 14×14 → 28×28 | - |
| Concat3 | concat | 6 + 6 → 12 | ← Conv1 (6×28×28) |
| Conv6 | 3×3, pad=1 | 12 → 1 | - |
| ReLU6 | - | 28×28 | - |
| Upsample4 | bilinear, scale=32/28 | 28×28 → 32×32 | - |
| Sigmoid | - | 32×32 | - |
