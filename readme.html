MNIST 图像分割 — 从零实现 LeNet-5 魔改版

⚡ 不用 PyTorch，不用 TensorFlow，纯 NumPy 实现图像分割

📖 项目简介

本项目从零实现了一个图像分割模型，基于 LeNet-5 魔改，在 MNIST 数据集上进行前景（数字）分割。模型将输入图像中的每个像素分类为“数字”或“背景”，输出与输入同分辨率的二值掩码。

  • ✅ 纯 NumPy 实现，无任何深度学习框架依赖
  • ✅ 完整的前向传播 + 反向传播（手写梯度）
  • ✅ 对称的 U-Net 风格架构 + 跳跃连接
  • ✅ 支持 断点续训，随时保存和加载模型
  • ✅ 支持 Dice Loss 和加权交叉熵切换

🎯 项目背景

从分类到分割

任务 输入 输出 目标
分类 (LeNet-5) 32×32 图片 1 个数字 (0~9) 识别是什么数字
分割 (本项目) 32×32 图片 32×32 掩码 (0/1) 识别每个像素是否属于数字

分割的难点在于需要像素级的空间精度，而不仅仅是全局类别判断。

  • 为什么不用框架？ 理解深度学习“学习”的本质——梯度就是矩阵乘法；掌握反向传播的每一个细节；拥有完全透明的代码，调试有底气。

🧠 模型架构

编码器 (Encoder) — LeNet-5 风格

层 操作 输入 → 输出 通道变化
Input-32×321
Conv15×5, pad=0, stride=132×32 → 28×281 → 6
ReLU1-28×286
Pool12×2, stride=228×28 → 14×146
Conv25×5, pad=0, stride=114×14 → 10×106 → 16
ReLU2-10×1016
Pool22×2, stride=210×10 → 5×516
Conv3 (瓶颈)1×1, pad=05×5 → 5×516 → 16

关键设计 瓶颈保留 5×5 空间信息，而不是压缩到 1×1。

Upsample2bilinear, scale=1.410×10 → 14×14-
Concat2concat6 + 6 → 12← Pool1 (6×14×14)
Conv53×3, pad=112 → 6-

🛠️ 损失函数

1. 加权交叉熵（当前使用）

loss = -mean(pos_weight * y * log(p) + (1-y) * log(1-p))

适用场景 训练初期，防止模型预测全背景

2. Dice Loss

loss = 1 - (2 * intersection + eps) / (union + eps)

适用场景 训练后期，直接优化 IoU 指标

切换方法

# 在 train_seg.py 中
# 使用加权交叉熵
loss, cache = binary_cross_entropy(pred, batch_y, pos_weight=10.0)

# 使用 Dice Loss
loss, cache = dice_loss(pred, batch_y)

💡 经验总结

为什么分割不能用 1×1 的瓶颈？

1×1×16 = 16 个数字
32×32 = 1024 个像素
16 → 1024，信息量放大 64 倍，不可能还原出精确位置

分割需要保留空间信息，瓶颈至少保留 5×5。

为什么需要跳跃连接？

  • 编码器逐层压缩，丢失了细节（边缘、纹理）
  • 跳跃连接把这些细节直接传给解码器
  • 让模型同时拥有“全局理解”和“局部精度”

为什么先用加权交叉熵，再用 Dice Loss？

  • 训练初期：交叉熵梯度稳定，防止模型“躺平”
  • 训练后期：Dice Loss 直接优化目标指标 IoU
